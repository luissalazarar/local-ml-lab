# Ejemplos reproducibles

Los cinco recorridos guiados usan Excel `.xlsx` con una hoja analizable `Datos` y una hoja humana `Guía`. Regresión y drivers comparten el mismo workbook; clasificación, pronóstico y exploración tienen estructuras propias. Todos son sintéticos, usan semilla fija y no representan personas ni empresas reales.

CSV y Parquet se conservan para verificar formatos. Regenera todo con `cd backend && uv run python ../scripts/generate_examples.py`.

No se incluye aquí ningún dataset de terceros. Los enlaces públicos de la sección Guía son referencias externas y requieren revisar estructura, licencia y objetivo antes de analizarlos.
