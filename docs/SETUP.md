# Instalación

Para uso normal ejecuta `sh scripts/setup.sh` en macOS/Linux o `powershell -ExecutionPolicy Bypass -File scripts/setup.ps1` en Windows y abre `http://localhost:3000`. Ambos instaladores construyen Compose, esperan que la aplicación esté lista y ejecutan dentro de Docker el smoke sintético con regresión, clasificación, forecast y exportaciones. Docker instala Python, Node y dependencias dentro de imágenes; no se requieren instalaciones globales adicionales. La instalación se verificó localmente en macOS Apple Silicon y la CI construye y prueba imágenes Linux amd64; el script PowerShell está disponible, pero Windows permanece declarado como no verificado físicamente. Consulta la sección «Instalación asistida por IA» del [README](../README.md).
