# Instalación

Para uso normal ejecuta `docker compose up --build` y abre `http://localhost:3000`. Docker instala Python, Node y dependencias dentro de imágenes; no se requieren instalaciones globales adicionales. La instalación se verificó localmente en macOS Apple Silicon y la CI construye y prueba imágenes Linux amd64; Windows permanece declarado como no verificado. Consulta la sección «Instalación asistida por IA» del [README](../README.md) para la verificación automatizada.
