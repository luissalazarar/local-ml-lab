# Instalación

Para uso normal ejecuta `sh scripts/setup.sh` en macOS/Linux o `powershell -ExecutionPolicy Bypass -File scripts/setup.ps1` en Windows y abre `http://localhost:3000`. La única dependencia de ejecución en el host es un motor Docker activo con Compose v2. En Windows y macOS, Docker Desktop es la ruta más simple porque incluye motor, CLI y Compose; Windows también necesita WSL 2. Linux puede usar Docker Engine con el plugin Compose. Git es opcional y Python y Node se ejecutan dentro de Docker. Ambos instaladores construyen Compose, esperan que la aplicación esté lista y ejecutan el smoke sintético. En Windows, el instalador también inicia Docker Desktop si está cerrado y espera hasta diez minutos por el motor. La instalación se verificó localmente en macOS Apple Silicon y la CI construye y prueba imágenes Linux amd64. En Windows se verificaron físicamente el arranque y uso local el 04-10-2026 en un ASUS ROG Strix G16 G614JIR con Intel Core i9-14900HX y NVIDIA RTX 4070; es evidencia de ese equipo, no compatibilidad universal con Windows. La sección «Instalación asistida por IA» del [README](../README.md) define una sola autorización global para todos los prerequisitos y pasos posteriores.
