# Contribuir

Abre cambios pequeños, añade pruebas proporcionales y explica cualquier modificación de métricas o políticas. Ejecuta las pruebas de [docs/TESTING.md](docs/TESTING.md). No incluyas datasets privados, secretos ni artifacts de usuario.

Para proponer un cambio abre un issue o un pull request. Las contribuciones aceptadas se integran a través del flujo de desarrollo del autor y llegan a este repositorio en el siguiente release.
